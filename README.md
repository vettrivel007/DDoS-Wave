## **Unleash the Wave of Packets for Ethical Testing**  


**DDoS-Wave** is a powerfull and customizable network stress-testing tool crafted for cybersecurity enthusiasts, professionals, and learners. Simulate a flood of TCP packets with randomized spoofed IPs to test the resilience of systems in controlled environments. Whether you're learning about network security or performing ethical penetration testing, DDoS-Wave gives you the edge.

## 🚀 **Key Features**
- 🌐 **Customizable Target**: Easily specify the target IP and port for testing.  
- 🎭 **Spoofed IPs**: Generates realistic, randomized source IPs to simulate distributed traffic.  
- ⚡ **Efficient Packet Sending**: Sends packets at high speed with controlled intervals.  
- 🔧 **User-Friendly**: Minimal setup and intuitive interface.  

---

## 🛠️ **How It Works**  
**DDoS-Wave** crafts and sends TCP packets to the specified target IP and port with a spoofed source IP. This simulates a distributed denial-of-service (DDoS) attack for learning and testing purposes.  

### **Example Flow**:
1. Enter the target IP and port.  
2. Watch packets flood the target with randomized spoofed sources.  
3. Interrupt at any time to see a summary of packets sent.

## 📥 **Installation**
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/DDoS-Wave.git
   ```

2. Navigate to DDos-Wave :
   ```bash
   cd DDoS-Wave
   ```

3. Install the required dependencies:
   ```bash
   pip install scapy
   ```

4. Run the script:
   ```bash
   python3  ddos_wave.py
   ```

---

## 🔧 **Usage**  
1. **Run the Script**:
   ```bash
   python3 ddos_wave.py
   ```

2. **Enter the Target Details**:
   ```plaintext
   Enter the Target IP Address: <Target-IP>
   Enter the Target Port: <Target-Port>
   ```

3. **Watch the Flood**:  
   Packets will start flooding the target, displaying details like spoofed source IPs, source ports, and progress.  
   ```plaintext
   [+] Spoofed Source IP: 203.0.113.45
       [+] Packet #1 sent from 203.0.113.45:3456 to <Target-IP>:<Target-Port>
       [+] Packet #2 sent from 203.0.113.46:3457 to <Target-IP>:<Target-Port>
   ```

4. **Stop Anytime**: Press `Ctrl+C` to stop the process and view the total packet count sent.
